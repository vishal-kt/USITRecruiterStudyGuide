# US IT Staffing Recruiter — Ultimate Study Guide

## Overview
A comprehensive, interactive web-based study guide designed to help aspiring and current IT recruiters master US staffing recruitment from fundamentals to senior-level expertise.

## Features

### 📚 Structured Learning Paths
- **Junior Recruiter Track** — Foundations through advanced daily routines
- **Senior Recruiter Track** — Account management, rate negotiation, team leadership
- **90-Day Roadmap** — Progressive 12-week study plan with checkpoints
- **Self-Quiz** — 6 interactive questions to test knowledge retention

### 🎓 Core Content Zones
1. **US Staffing Foundations** — Employment types (W2, C2C, 1099), visa categories, rate calculations, vendor layers, time zones
2. **Sourcing Mastery** — Boolean search, platform sourcing strategies, fake resume detection
3. **Technical Knowledge** — IT domain map, job description analysis, skill synonyms
4. **Communication Skills** — Candidate call scripts, email templates, objection handling
5. **Compliance & Legal** — RTR (Right to Represent), I-9, E-Verify, background checks, MSA basics
6. **Tools & ATS** — Applicant Tracking Systems, KPIs, metrics for performance tracking
7. **Daily Routine** — Weekly activity tracker, 7-day structured schedule
8. **Senior Topics** — Account management, advanced negotiation, bench sales, team delivery

### 🌙 Night Mode
- **Theme Toggle** — Easy light/dark mode switching
- **System Preference** — Auto-detects OS dark mode preference
- **Persistent** — Saves your theme choice to browser storage
- **Full Coverage** — All UI elements optimized for dark theme

### 🎯 Interactive Elements
- **Expandable Cards** — Click to reveal detailed information
- **Progress Tracker** — Monitor weekly activities and 90-day roadmap completion
- **Career Path Visualization** — Track progression from Junior → Senior → Lead → Manager
- **Daily Grid** — Color-coded task schedule for structured learning
- **Quiz Scoring** — Real-time feedback and performance analysis

### 📊 Content Includes
- **Tables & Comparisons** — Employment types, visa categories, platforms, ATS systems
- **Checklists** — Actionable task lists with sub-notes
- **Tip Boxes** — Key insights and professional advice
- **Warning Boxes** — Compliance pitfalls and risk factors
- **Email Templates** — Ready-to-use outreach, follow-up, and offer scripts
- **Boolean Strings** — Production-ready search queries for major platforms

## How to Use

1. **Open** `index.html` in any modern web browser
2. **Navigate** using the tab system at the top:
   - Junior Recruiter (with section navigation)
   - Senior Recruiter
   - 90-Day Roadmap
   - Self-Quiz
   - Career Path

3. **Expand Cards** by clicking to see full details
4. **Track Progress** using the roadmap checkboxes and activity trackers
5. **Toggle Night Mode** using the 🌙 button (top-right corner)
6. **Take the Quiz** to assess your knowledge

### Key Topics Covered

### KPIs & Benchmarks
- **Junior Recruiter** — 5–8 submissions/day, 2–4 interviews/week, 1–2 closures/month
- **Senior Recruiter** — 8–12 submissions/day, 5–8 interviews/week, 3–5+ closures/month
- **Interview-to-Submission Ratio** — 1:4–1:6 (quality indicator)
- **Fill Ratio** — 20–30% (junior), higher for seniors
